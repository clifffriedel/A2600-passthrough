# Passthrough for the Atari 2600

This is a game I wrote in Batari Basic for the Atari 2600.  The latest, and likely final, version is v1.02 and is in the bin/ folder.  Just copy it to a Harmony or other SD card device to play it on real hardware.  It can also be played on emulator as well by running the .bin file.

# Gameplay

You've been trapped at the bottom of a cave and are running out of air! Ascend the cave and escape by hitting up on the joystick when the path is clear (no lines).  There are bonuses (green) and penalties (red) you can hit as you ascend.  The game is over when you ascend all 10 levels or the score hits zero!
